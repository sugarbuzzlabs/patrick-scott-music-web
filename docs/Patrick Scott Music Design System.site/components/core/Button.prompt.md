Uppercase poster-style action button; use `solid` (amber) for the single primary action per view, `outline` for secondary, `ghost` for tertiary/inline.

```jsx
<Button variant="solid" size="lg" href="#booking">Book a show</Button>
<Button variant="outline">See all dates</Button>
```

Variants: solid/outline/ghost; sizes sm/md/lg; `full`, `disabled`, `href`.
