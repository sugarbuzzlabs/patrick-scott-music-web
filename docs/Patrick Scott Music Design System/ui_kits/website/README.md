# Website UI kit — patrickscottmusic.com

Interactive click-through of the artist site. Three screens composed from the design-system components:

- **Home** (`Home.jsx`) — full-bleed B&W hero with protection gradient, upcoming shows (ShowRow), streaming links (PlatformLink), video cards (Card), email capture.
- **Booking** (`Booking.jsx`) — pitch + booking request form (Input/Select/Textarea/Button), fake submit state.
- **Press kit** (`PressKit.jsx`) — bio, approved photos, set formats, contact, Venmo tip pattern.

Global chrome in `index.html`: sticky blurred nav with PS monogram, Tip dialog (Venmo/PayPal link-out — the recommended payment approach for a static site), footer.
